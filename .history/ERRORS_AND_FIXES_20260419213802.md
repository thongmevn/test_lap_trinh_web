## 🔴 **LỖI 1-7: index.php (7 lỗi)**

### ❌ **LỖI 1: Dòng 72 - SELECT MAX với string condition**

**Nguyên nhân:** Sử dụng `mysqli_query()` với hard-coded string '1'

**Vị trí:** `index.php` dòng 72

**Code SAI:**
```php
$guests_q = mysqli_query($con,"SELECT MAX(adult) AS `max_adult`, MAX(children) AS `max_children` 
  FROM `rooms` WHERE `status`='1' AND `removed`='0'");
```

**Vấn đề:**
- Direct query không prepared
- Hard-coded condition dễ bị lỗi
- Không tái sử dụng được

**Code SỬA:**
```php
$guests_q = select("SELECT MAX(adult) AS `max_adult`, MAX(children) AS `max_children` 
  FROM `rooms` WHERE `status`=? AND `removed`=?", [1, 0], 'ii');
```

### ❌ **LỖI 2: Dòng 117 - SELECT features với room_id variable**

**Nguyên nhân:** Variable interpolation `$room_data[id]` không được escape

**Vị trí:** `index.php` dòng 117

**Code SAI:**
```php
$fea_q = mysqli_query($con,"SELECT f.name FROM `features` f 
  INNER JOIN `room_features` rfea ON f.id = rfea.features_id 
  WHERE rfea.room_id = '$room_data[id]'");
```

**Vấn đề:**
- ❌ SQL Injection vulnerability
- ❌ Không escape $room_data[id]
- ❌ Có thể query bị lỗi nếu id chứa ký tự đặc biệt

**Code SỬA:**
```php
$fea_q = select("SELECT f.name FROM `features` f 
  INNER JOIN `room_features` rfea ON f.id = rfea.features_id 
  WHERE rfea.room_id = ?", [$room_data['id']], 'i');
```

### ❌ **LỖI 5: Dòng 167 - SELECT rating_review**

**Nguyên nhân:** Direct `mysqli_query()` với biến query không prepared

**Vị trí:** `index.php` dòng 167

**Code SAI:**
```php
$rating_q = "SELECT AVG(rating) AS `avg_rating` FROM `rating_review`
  WHERE `room_id`='$room_data[id]' ORDER BY `sr_no` DESC LIMIT 20";

$rating_res = mysqli_query($con,$rating_q);
```

**Vấn đề:**
- ❌ SQL Injection - `$room_data[id]` không escape
- ❌ No prepared statement

**Code SỬA:**
```php
$rating_q = "SELECT AVG(rating) AS `avg_rating` FROM `rating_review`
  WHERE `room_id`=? ORDER BY `sr_no` DESC LIMIT 20";
$rating_res = select($rating_q, [$room_data['id']], 'i');
```

## 📝 **NGUYÊN NHÂN CHUNG**

```
1. ❌ Sử dụng mysqli_query() thay vì hàm select()
2. ❌ Variable interpolation: '$room_data[id]' không escape
3. ❌ Hard-coded string '1' thay vì integer 1
4. ❌ Không sử dụng prepared statements (parameterized queries)
5. ❌ Không validate/sanitize user input
```

## ✅ **GIẢI PHÁP CHUNG**

### Mẫu 1: Query đơn giản
```php
// ❌ CŨ:
$res = mysqli_query($con,"SELECT * FROM table WHERE id='$id'");

// ✅ MỚI:
$res = select("SELECT * FROM table WHERE id=?", [$id], 'i');
```

### Mẫu 2: Query multiple values
```php
// ❌ CŨ:
$res = mysqli_query($con,"SELECT * FROM table WHERE status='1' AND removed='0'");

// ✅ MỚI:
$res = select("SELECT * FROM table WHERE status=? AND removed=?", [1, 0], 'ii');
```

### Mẫu 3: Query tổng hợp
```php
// ❌ CŨ:
$fac_q = mysqli_query($con,"SELECT f.name FROM facilities f 
  INNER JOIN room_facilities rfac ON f.id = rfac.facilities_id 
  WHERE rfac.room_id = '$room_id'");

// ✅ MỚI:
$fac_q = select("SELECT f.name FROM facilities f 
  INNER JOIN room_facilities rfac ON f.id = rfac.facilities_id 
  WHERE rfac.room_id = ?", [$room_id], 'i');
```
